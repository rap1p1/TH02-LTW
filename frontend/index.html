== BACKEND (ASP.NET Core) ==

Yeu cau: Cai .NET 8 SDK
Tai tai: https://dotnet.microsoft.com/download

1. Mo terminal, vao thu muc backend:
   cd backend/ComicStore.API

2. Restore cac thu vien:
   dotnet restore

3. Cai EF Core CLI tools (chi can cai 1 lan):
   dotnet tool install --global dotnet-ef

4. Tao migration lan dau:
   dotnet ef migrations add InitialCreate

5. Tao database va ap dung migration:
   dotnet ef database update

6. Chay server:
   dotnet run
   -> API chay tai: http://localhost:5000
   -> Swagger UI:   http://localhost:5000/swagger

(hoac dung Live Server trong VS Code)

== CAC ENDPOINT API ==

Truyen (Comics):
  GET    /api/comics        - Lay tat ca truyen
  GET    /api/comics/{id}   - Lay truyen theo ID
  POST   /api/comics        - Them truyen moi
  PUT    /api/comics/{id}   - Cap nhat truyen
  DELETE /api/comics/{id}   - Xoa truyen

Don hang (Orders):
  GET    /api/orders        - Lay tat ca don
  GET    /api/orders/{id}   - Lay don theo ID
  POST   /api/orders        - Tao don moi
  PUT    /api/orders/{id}   - Cap nhat don
  DELETE /api/orders/{id}   - Xoa don

== KET NOI DATABASE ==
- Chinh sua connection string trong backend/ComicStore.API/appsettings.json
- Mac dinh dung SQLite (file comicstore.db)
- Co the doi sang SQL Server bang cach chinh sua Program.cs
